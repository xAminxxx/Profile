# Images Directory

## How to Add Your Photos

### Profile Photo

1. Add your professional photo here: `profile.jpg`
2. Recommended size: **512x512 pixels** (square)
3. Format: JPG or PNG
4. Keep file size under 500KB for fast loading

### Project Screenshots (Optional)

Create a `projects` folder and add:

- `hedera-blockchain.png`
- `intelligent-classroom.png`
- `geex.png`

Recommended size: **1200x630 pixels** (16:9 aspect ratio)
